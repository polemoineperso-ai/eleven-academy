# ELEVEN ACADEMY

Application de révision pour l'examen de la licence d'agent sportif (épreuve générale du CNOSF, puis épreuve FFF).
QCM au format de l'examen, Revue VAR avec l'article de loi exact et sa date, révision espacée, divisions et trophées.

- `index.html` : l'application (page unique, images intégrées).
- `content/v1.json` : les questions, fiches et sources (vérifiées le 3 novembre 2026).
- `config.js` : connexion Supabase (vide = progression gardée sur l'appareil).
- `supabase/schema.sql` : tables et règles d'accès à créer dans Supabase.

Le contenu juridique cite les textes officiels (Légifrance, CNOSF, FIFA, FFF, LFP). Il ne remplace pas la lecture des textes en vigueur.
